## 제출 공지 변경

사용자가 전달한 공지에 따라 마무리 과제는 GitHub 저장소 URL과 40자리 커밋 SHA로 제출합니다. 업데이트·파일 업로드·package-app은 제출 선행 조건이 아닙니다. 제출 폼 위치와 실제 접수·판정은 아직 확인하지 않았습니다. 운영 안내 원문을 직접 열어 검증한 것으로 기록하지 않습니다.

제출 시 GitHub에 있는 최종 커밋을 선택하고 작업 폴더의 `git rev-parse HEAD`와 대조합니다. 추가 PR 병합 전후 SHA가 달라지므로 과거 제출 후보 번호를 재사용하지 않습니다. 설치형 앱 배포와 과제 제출은 별개입니다.
