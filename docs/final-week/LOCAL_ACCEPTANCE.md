기준: 2026-10-28. 근거는 사용자 제공 화면 HTML과 사용자 직접 확인 보고입니다. 개인 경로·계정·키·원본 HTML은 공개 기록에 포함하지 않습니다.

## 기능 재확인 순서 (제출 전 반복 필수 아님)

1. 기존 승인 폴더에서 공식 실행 도구로 켭니다.
2. 다시 조회 → 관찰 기준 시각·방화벽·이벤트 한계 표시를 확인합니다. 관찰과 보안 판정을 구분해야 합니다.
3. 두 번째 조회 → 자원 변화와 직전 비교를 확인합니다.
4. 출처를 펼친 뒤 필터를 바꿉니다. 최신 수치 카드와 열린 출처는 유지되어야 합니다.
5. Tab으로 버튼·출처·필터·기록·해석 안내에 접근하고 Enter/Space로 펼침을 조작합니다.
6. 좁은 창에서 글자·선택 항목이 잘리지 않는지 확인합니다.
7. 기록을 지운 뒤 관찰·최신 수치·기록이 남지 않아야 합니다. 재조회하면 1회부터 시작합니다.

정상 수치를 만들기 위해 방화벽이나 보안 정책을 바꾸지 않습니다. 결측·부분 집계·실패·취소 경합은 모의 테스트와 별도로 표시합니다. 새 관찰 요약과 접기 UI도 이후 사용자 정상 보고로 반영했습니다. 다만 모든 화면 폭·전체 키보드 조작까지 확인했다고 확대하지 않습니다.
