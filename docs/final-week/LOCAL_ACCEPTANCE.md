# 사용자 로컬 확인표

현재 사용자 보고와 미확인 범위는 [WAITING_HANDOFF](WAITING_HANDOFF.md)를 따른다. 아래 표는 상세 증거 수집 양식으로, 채워지지 않은 개별 수치·조건을 성공으로 추정하지 않는다. 기존 0.2.14 데모 필터·상세 확인(#131)을 새 PC 기능의 성공으로 옮기지 않는다. 비밀값, 개인 경로, 사용자명, IP/MAC, 실제 이벤트 원문은 적지 않는다.

## 실행 버전

- 날짜/시각(한국 시간): 미확인
- 소스 커밋(개발 저장소의 `git rev-parse HEAD`, ZIP은 별도 근거가 없으면 미확인): 미확인
- OS / `node --version`: 미확인
- 실행: 0.2.19 공식 연동: `on-client`에서 `npm.cmd run demo`

| 메모리 | total−free 기준 값·GiB·비율; 작업 관리자 집계와 차이가 있으면 기록 | 미확인 |
| 디스크 | 시스템 볼륨 여유/전체 또는 확인 불가 | 미확인 |
| 네트워크 | 어댑터 링크 Up/전체 수; 인터넷·SDP 인증 성공이라고 표시하지 않음 | 미확인 |
| 방화벽 | 세 프로필 설정 또는 확인 불가; 설정 변경 없음 | 미확인 |
| System/Application | 각각 24시간 경고·오류와 집계 범위 또는 확인 불가 | 미확인 |

| 취소·지우기 | 늦은 응답이 삭제한 기록을 되살리지 않음 | 미확인 |

실패를 만들려고 보안 정책을 바꾸지 않는다. 서버를 종료한 뒤 화면에서 조회해 연결 실패 안내를 확인하는 정도로 충분하다. 강제 오류·취소 경합은 자동 모의 테스트도 별도 근거로 남긴다.

## 5일차 첫 사용자 관찰

- 다른 사람이 QUICKSTART만 보고 실행했는가: 미실시
- 막힌 단계와 안전한 오류 코드: 미확인
- 안내/코드 중 보완할 위치: 미확인
- 보완 뒤 다른 사람의 재실행: 미실시
- 본인이 새 폴더에서 따라 실행한 결과: 미실시

다른 사람이 없으면 자신의 다른 폴더에서 확인하되, 동료 관찰이라고 기록하지 않는다.

- 학생 PC API가 승인된 설치형 host에서 동작하는가: 미확인
- 같은 소스의 네 포장 파일 생성: 미실시
- 기본 패키지 새 경로 설치·실행: 미실시
- Inno Setup 사용자 단위 설치·실행·제거: 미실시
- setup.exe SHA-256: 미확인
- 실제 화면 캡처와 시연: 미실시
- 공식 제출 경로·접수 결과: 미확인
