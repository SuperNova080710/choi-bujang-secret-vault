# 앱 소개·데이터 처리·시연 자료 초안

현재 학생 앱의 배포 소개 준비 자료입니다. 스토어 등록·심사·설치 검증 완료 문서가 아닙니다. 새 관찰 요약은 PR 병합 후 사용자 정상 보고로 확인했습니다. 제출 기준은 [최종 기록](FINAL_SUBMISSION.md)입니다.

## 짧은 소개

내 PC의 자원과 시스템 기록을 직접 조회하고, 이전 값과 비교하는 PC 타임라인입니다. CPU·메모리·디스크·네트워크 구성·방화벽 설정·Windows 경고와 오류 건수를 출처 및 측정 시각과 함께 확인할 수 있습니다.

## 기능 설명

조회 버튼을 누르면 앱 서버가 실행되는 PC의 상태를 한 번 읽습니다. 최근 30회 기록을 보관하고 자원 사용량 변화를 비교합니다. 필요한 항목만 필터링하거나 조회 기록을 지울 수 있습니다. 확인하지 못한 값은 0이나 정상으로 바꾸지 않고 확인 불가로 표시합니다.

관찰 요약에서는 자원 변화, 꺼진 방화벽 프로필, 이벤트 집계와 한계를 보여 줍니다. 이 정보는 원인을 조사할 때 참고할 자료이며 침해 탐지·자동 차단·제품 안전 인증을 뜻하지 않습니다.

## 기능과 제한

- PC 기록은 학생 화면의 메모리에 최대 30회 보관합니다. 페이지를 새로고침하거나 닫으면 사라지며 영구 저장·내보내기는 구현하지 않았습니다.
- Windows 이벤트는 System·Application 최근 24시간 합산 최대 5,000건 집계입니다. 일부 집계와 0건을 구분하며 이벤트 본문을 표시하지 않습니다.
- 계정·AI 승인 및 모델 API 점검은 Windows에서 확인했습니다. 실제 사건 설명 생성·조치 효과는 검증하지 않았습니다.
- SDP 설정은 별도이며 이번 과정에서 인증서를 발급하지 않아 미연결입니다. 화면의 연결 없음 상태를 정상 연결로 숨기지 않습니다.
- GitHub 서비스는 연결 전 안내만 구현했습니다. 사용량·비용·보안 조회는 아직 지원하지 않습니다.
- OSV는 대상 프로젝트·실제 설치 파일·공개 조회 승인 목록을 설정해야 합니다. 사용자가 jose 6.2.12의 실제 조회 성공을 확인했습니다. 해당 시각·승인 범위에 한정됩니다.

## 데이터 처리 설명 초안

| 구분 | 읽는 정보와 처리 |
|---|---|
| 학생 PC 타임라인 | 로컬 앱 서버가 비식별 집계값을 읽어 브라우저에 전달. 학생 화면은 메모리만 사용하고 이 기록을 외부로 전송하지 않음 |
| Windows 시스템 정보 | 방화벽 세 프로필 상태와 이벤트 건수. 이벤트 본문·사용자·호스트 주소는 PC 조회 응답에 포함하지 않음 |
| 계정·AI 연결 | 공식 승인 흐름과 로컬 자격 보관소 사용. 이 기능에는 외부 서비스 통신이 있으므로 앱 전체를 완전 오프라인이라고 소개하지 않음 |
| OSV 선택 조회 | 승인된 공개 npm 패키지명·정확한 설치 버전을 OSV에 보냄. 전체 lock·로컬 경로·키를 보내지 않음 |
| GitHub 카드 | 현재 외부 조회·인증정보 입력·저장 없음 |

이 설명은 구현 범위에 관한 기술 자료입니다. 실제 배포 전 전체 의존 서비스의 수집·보관 정책, 배포자 연락처·재배포 조건을 확인해 공개용 개인정보 안내를 확정해야 합니다.

## 3분 시연 순서

| 순서 | 조작 | 설명 |
|---|---|---|
| 1 | 공식 실행기로 앱 실행 | 승인된 기존 프로젝트 폴더 사용. SDP 상태와 PC 실측 구분 |
| 2 | PC 다시 조회 | 6개 항목 중 읽은 값/확인 불가, 측정 시각 확인 |
| 3 | 출처 펼치기 → 다시 조회 | 이전 값과 비교, 출처 펼침 유지 |
| 4 | 기록 필터 변경 | 최신 수치와 과거 기록의 역할 구분 |
| 5 | 관찰 요약 설명 | 수치 변화는 원인·침해 판정이 아님을 설명 |
| 6 | 기록 지우기 → 다시 조회 | 저장 범위와 초기화 확인 |
| 7 | AI·GitHub·SDP 상태 설명 | 확인된 연결과 보류된 연결을 구분. 유료 생성 요청 반복 불필요 |

캡처 후보: 첫 조회 요약, 두 번째 조회 비교, 필터 적용 기록, 초기화 안내. 계정 정보·키·토큰·개인 경로를 가립니다. 아직 실제 캡처 파일을 제작하거나 사용자 영상으로 확인하지 않았습니다.

## 스토어 게시 전 남은 항목

실제 배포 패키지·다른 PC 설치/실행/제거, 제공 실행 환경 재배포 권한, 아이콘 사용 권한, 배포 계정과 공개 개인정보 안내, 지원 OS 및 서비스 제한을 확인해야 합니다. 이 자료만으로 스토어 게시 준비 완료를 선언하지 않습니다. 스토어 계정 등록이나 실제 게시를 수행하지 않았습니다.
